# ☕ Café Aurora

Uma landing page desenvolvida em **Angular**, criada para apresentar a identidade de uma cafeteria de forma moderna, elegante e acolhedora.

O projeto combina uma experiência visual agradável com uma estrutura organizada, destacando a marca, seus produtos e a proposta do Café Aurora.

## ✨ Sobre o projeto

O **Café Aurora** é um projeto de desenvolvimento front-end que busca transmitir a atmosfera de uma cafeteria por meio de uma página intuitiva e visualmente atrativa.

A landing page foi desenvolvida com Angular, utilizando tecnologias web para estruturar o conteúdo, estilizar a interface e implementar os elementos da página.
Link da pagina: [Acesse aqui](https://cafe-aurora-red.vercel.app/)

## 🚀 Tecnologias utilizadas

- **Angular** — estrutura e desenvolvimento da aplicação.
- **TypeScript** — lógica e tipagem do código.
- **HTML5** — estruturação do conteúdo.
- **CSS3** — estilos, layout e responsividade.

## 🎯 Objetivos do projeto

- Desenvolver uma landing page moderna para uma cafeteria.
- Criar uma apresentação visual consistente com a identidade da marca.
- Organizar o conteúdo para facilitar a navegação.
- Praticar desenvolvimento front-end com Angular.
- Aplicar conceitos de layout, estilização e experiência do usuário.

## 🖥️ Funcionalidades

- Apresentação da marca Café Aurora.
- Organização visual do conteúdo da landing page.
- Seções destinadas à apresentação da cafeteria e de seus produtos.
- Interface desenvolvida com foco na experiência do usuário.

> As funcionalidades descritas devem ser ajustadas conforme os recursos realmente implementados no projeto.

## 📦 Como executar o projeto

### Pré-requisitos

- Node.js compatível com a versão do Angular utilizada.
- npm.
- Angular CLI, caso queira utilizar os comandos `ng` diretamente.

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Entre na pasta do projeto

```bash
cd cafe-aurora
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute a aplicação

```bash
ng serve
```

Acesse no navegador:

```text
http://localhost:4200
```

## 🏗️ Build de produção

Para gerar a versão de produção da aplicação:

```bash
ng build
```

Os arquivos compilados serão gerados no diretório de saída configurado pelo Angular.
